# Albanian Trailblazers — Project Context

## What this is
Static website for Albanian Trailblazers, a free youth-led mentorship NGO 
connecting Albanian students with professionals globally. Hosted on GitHub Pages.
Plain HTML, CSS, vanilla JS only. No frameworks, no build tools, no npm.

## Design system
- Hero/dark sections: #15130E background
- Body/light sections: #F7F3EC (warm cream)
- Primary accent: #E05535 (eagle red)
- Headings: Space Grotesk (Google Fonts)
- Body: Inter (Google Fonts)
- Mobile-first. Breakpoints: 768px (tablet), 1200px (desktop)

## File structure
- index.html — landing page (only page built so far)
- css/styles.css — all styles
- js/main.js — scroll behavior, mobile nav, IntersectionObserver
- assets/images/ — logos and event photos
- assets/icons/ — SVG social icons

## Key decisions already made
- No JS libraries, no jQuery, no animation libraries
- Noise texture on dark hero section only
- Primary CTA throughout is always "Apply now"
- Social links: Instagram, LinkedIn, YouTube
- Contact: albanian.trailblazers@gmail.com
- Updates/blog lives on Wix for now, link out to albaniantrailblazers.com/updates

## Tone
Bold and ambitious but warm — educational NGO, not a tech startup.
